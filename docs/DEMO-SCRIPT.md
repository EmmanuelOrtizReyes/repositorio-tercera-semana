# Guion de demostración (5–7 minutos)

1. Presentar Dulces Emma y su objetivo de administrar inventario.
2. Mostrar GitHub, backlog, ramas y Pull Request.
3. Mostrar la interfaz en móvil, tableta y escritorio.
4. Registrar un usuario y explicar validaciones.
5. Iniciar sesión y mostrar la ruta protegida.
6. Mostrar carga, vacío, error y lista de productos.
7. Registrar un producto y mostrar el mensaje de éxito.
8. Provocar una validación inválida y explicar cliente/servidor.
9. Mostrar Prisma, PK, FK y PostgreSQL.
10. Ejecutar la colección Postman.
11. Ejecutar pruebas unitarias y E2E.
12. Mostrar navegación por teclado, checklist de accesibilidad y OWASP.

Cerrar indicando qué evidencias fueron generadas por el proyecto y cuáles deben capturarse manualmente.

Mostrar los resultados de pruebas tal como se ejecuten en ese momento; no presentar una captura E2E que no haya pasado con PostgreSQL disponible.
