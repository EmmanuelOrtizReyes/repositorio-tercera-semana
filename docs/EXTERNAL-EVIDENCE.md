# Evidencias externas

Estas evidencias deben capturarse manualmente; no se inventan resultados.

## W3C

Capturar la pantalla donde se vea el ejercicio, progreso o avance completado y la cuenta o módulo correspondiente.

## freeCodeCamp

Capturar el ejercicio, módulo o certificación, incluyendo nombre y porcentaje/progreso si aparece.

Guardar manualmente las imágenes en `docs/evidencias/w3c/` y `docs/evidencias/freecodecamp/`.
